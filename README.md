# فایل شو — نسخهٔ دسکتاپ

نرم‌افزار مدیریت بنگاه املاک، برای macOS و Windows.

نسخهٔ وب:
https://fileshow.ir

## دانلود

آخرین نسخه را از بخش Releases همین صفحه دانلود کنید:
https://github.com/hamedhosseini143/fileshow_tauri_release/releases/latest

- macOS: فایل `.dmg`
  - برای هر دو نوع Mac، با پردازندهٔ Apple و Intel.
- Windows: فایل `-setup.exe`

نسخهٔ Android را از مایکت نصب کنید.

## اولین اجرا

### macOS

اگر macOS گفت برنامه را نمی‌تواند باز کند:

۱. System Settings را باز کنید.
۲. به Privacy & Security بروید.
۳. پایین صفحه، کنار نام «فایل شو»، Open Anyway را بزنید.

این کار فقط یک بار لازم است.

### Windows

اگر پنجرهٔ آبی Windows protected your PC باز شد:

۱. More info را بزنید.
۲. Run anyway را بزنید.
